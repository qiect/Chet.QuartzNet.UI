# v2.2.0：多语言支持与文件数据迁移

v2.2.0 发布于 2026-05-29，主要解决两件事：界面只有中文，以及从文件存储切到数据库存储时需要手工搬数据。

## 1. 多语言支持

### 1.1 覆盖范围

- 语言：`zh-CN`、`en-US`；
- 页面：分析、作业管理、日志管理、通知管理；
- 内容：菜单、标题、表头、表单标签、按钮、提示与校验消息。

系统配置页是 v2.3.0 新增的，v2.2.0 尚未包含。

### 1.2 使用方式

点击右上角语言切换，选择中文或 English，界面立即生效，无需刷新。默认语言为 `zh-CN`，可在偏好设置中修改。

![多语言切换](/images/i18n-switch.png)

![英文界面 - 作业管理](/images/i18n-job-en.png)

### 1.3 实现方式

所有文案统一放在语言包中，通过 i18n 的 `$t()` 读取，不再硬编码在组件里。新增语言只需增加一份语言包文件。

## 2. 文件数据自动迁移

### 2.1 解决什么问题

早期用户通常先用文件存储起步，业务稳定后切换到数据库。此前需要自己写脚本读取 `App_Data/QuartzJobs/*.json` 再逐条写入数据库，v2.2.0 把这一步内置了。

### 2.2 迁移内容

- 作业数据；
- 作业日志；
- 系统设置；
- 通知消息。

已存在的记录按主键跳过，不会重复插入。

### 2.3 使用步骤

**第一步：安装数据库扩展包**

```bash
dotnet add package Chet.QuartzNet.EFCore.SQLite --version 2.2.0
```

**第二步：切换配置**

```json
{
  "ConnectionStrings": {
    "QuartzUI": "Data Source=quartzui.db"
  },
  "QuartzUI": {
    "StorageType": "Database",
    "DatabaseProvider": "sqlite"
  }
}
```

**第三步：注册迁移服务**

```csharp
using Chet.QuartzNet.UI.Extensions;

var builder = WebApplication.CreateBuilder(args);

builder.Services.AddQuartzUI(builder.Configuration);
builder.Services.AddFileDataToDatabase();   // 启动时执行一次文件 → 数据库迁移

var app = builder.Build();
app.UseQuartz();
app.Run();
```

**第四步：启动**

应用启动后自动执行，日志中会输出迁移结果。

### 2.4 执行条件

| 条件 | 行为 |
| ---- | ---- |
| `FileStoragePath` 不存在 | 跳过迁移 |
| `StorageType` 不是 `Database` | 记录警告并跳过，提示先切换存储 |
| 数据已存在 | 跳过该条记录 |

::: tip
这是“一次性、简单搬迁”的实现。当前版本建议使用「系统设置 → 数据迁移」向导：支持预检、进度、合并/覆盖/替换三种模式与迁移后校验，详见 [v2.6.0](/articles/15-v2.6.0)。
:::

## 3. 通知能力扩展

### 3.1 新增渠道

在微信公众号、企业微信、邮件、短信的基础上，新增：

- `webhook`：第三方 Webhook；
- `voice`：语音通知；
- `extension`：浏览器扩展；
- `app`：App 推送。

### 3.2 新增参数

PushPlus 配置增加：

| 参数 | 用途 |
| ---- | ---- |
| `Option` | 渠道编码：webhook 编码、企业微信应用编码、自定义邮件渠道编码 |
| `To` | 接收人：好友令牌或企业微信用户 id |
| `CallbackUrl` | 发送结果回调地址 |
| `Timestamp` | 消息有效期时间戳 |

通知配置界面会根据所选渠道动态展示需要填写的字段，避免无关参数干扰。

![通知渠道配置](/images/notification-channels.png)

## 4. 删除作业同步清理日志

此前删除作业后，执行日志仍留在存储中，时间久了会出现大量“孤儿日志”。v2.2.0 起删除作业会同时清理该作业的日志。

这个行为延续至今：删除作业的确认框会明确提示“相关的作业日志和配置也将被删除”。

## 5. 其他修复

| 问题 | 处理 |
| ---- | ---- |
| 401 错误传播到页面 catch 块 | 拦截后统一跳转登录，避免重复弹窗 |
| 暗色模式下样式选择器语法错误 | 修正选择器 |
| 通知配置项与渠道不匹配 | 按渠道动态展示与校验 |
| 代码格式不统一 | 统一格式与多处细节重构 |

## 6. 升级方式

```bash
dotnet add package Chet.QuartzNet.UI --version 2.2.0
```

数据库存储模式同步更新扩展包：

```bash
dotnet add package Chet.QuartzNet.EFCore.MySQL --version 2.2.0
dotnet add package Chet.QuartzNet.EFCore.PostgreSQL --version 2.2.0
dotnet add package Chet.QuartzNet.EFCore.SqlServer --version 2.2.0
dotnet add package Chet.QuartzNet.EFCore.SQLite --version 2.2.0
```

更新后直接启动即可，多语言无需额外配置。
