# v2.3.0：vxe-table 重构与系统配置

v2.3.0 发布于 2026-07-15，是一次偏“基础体验”的版本：把三个核心列表从 ant-design-vue Table 迁到 VbenAdmin 的 `useVbenVxeGrid`，新增系统配置页，并统一了详情弹窗与作业表单的布局。

## 1. 列表迁移到 vxe-table

涉及页面：作业管理、日志管理、通知管理。

### 1.1 变化

| 能力 | 说明 |
| ---- | ---- |
| 服务端分页 | 翻页、排序、筛选都走后端查询，前端不持有全量数据 |
| 服务端排序 | 表头排序字段与方向传给后端 |
| 排序持久化 | 排序状态保存到 localStorage，刷新后保留 |
| 搜索条件持久化 | 刷新或切换页面后筛选条件仍在 |
| 操作列悬停 | 鼠标移入行尾展开操作菜单，减少一次点击 |
| 列设置持久化 | 自定义显示列与列宽会被记住 |

作业列表中的 Cron、类名/API 等长文本使用省略显示，避免撑破布局。

![作业管理 - 新表格](/images/job.png)

![日志管理 - 新表格](/images/log.png)

### 1.2 日志时间范围查询

- 新增开始时间、结束时间的范围筛选；
- 时间参数使用 ISO 8601 格式，修复了此前日期参数导致 400 的问题；
- 执行时长列改为按秒显示，去掉列名中的单位后缀。

## 2. 系统配置页

新增「系统设置」页面，用于多实例环境下区分当前服务。

| 配置项 | 说明 |
| ------ | ---- |
| 服务名称 | 给调度服务起一个可识别的名字 |
| 环境标识 | DEV / TEST / UAT / PROD |
| 服务描述 | 补充说明，便于团队协作 |

这些信息保存在存储中，会随数据迁移一起复制。配置完成后，分析页顶部会展示服务名称与环境标签。

![分析页 - 服务标识](/images/analytices.png)

## 3. 分析页重写

- 图表结构重写，布局更紧凑；
- KPI 卡片图标更换：累计执行量使用 Activity，正常运行数使用 CircleCheckBig；
- 移除多余的 hover 动效；
- 服务标识融入页面头部。

## 4. 详情弹窗统一

日志详情、通知详情做了统一设计：

- 顶部 4px 状态色条：绿色成功、红色异常、蓝色运行中、橙色等待；
- 元数据改用 Descriptions 组件，标签对齐；
- Header 简化为“标题 + 状态标签”；
- 所有弹窗支持拖拽。

![日志详情](/images/log-detail.png)

![通知详情](/images/notification-detail.png)

## 5. 作业编辑页分区

- 表单按「基本信息 / 调度设置 / 作业配置 / 其他设置」分区；
- 标签列固定 110px，短字段两列排布，长字段独占一行；
- emoji 按钮改为文字按钮。

## 6. 工程与修复

| 问题 | 处理 |
| ---- | ---- |
| 表格无数据 | 统一 `proxyConfig` 返回格式 |
| 刷新后页面空白 | 修复 `#form` 插槽与 `formOptions` 冲突 |
| 日期查询返回 400 | 时间格式改为 ISO 8601 |
| 清空通知报错 | 修复旧变量引用 |
| 排序持久化失效 | 兼容 vxe 4.x 事件字段名变更 |
| 生产构建缺少图标 | icons 包 `exports` 指向源码，无需手动重建 |

## 7. 升级

```bash
dotnet add package Chet.QuartzNet.UI --version 2.3.0
```

数据库存储模式同步更新扩展包版本。更新后直接启动，新页面与列表能力自动生效，无配置变更。

## 8. 小结

| 方向 | 变化 |
| ---- | ---- |
| 列表 | vxe-table、服务端分页排序、条件与列设置持久化 |
| 配置 | 新增系统配置页，支持服务标识 |
| 分析页 | 图表重构、服务标识、KPI 图标 |
| 弹窗 | 状态色条、Descriptions、可拖拽 |
| 查询 | 日志时间范围筛选（ISO 8601） |
