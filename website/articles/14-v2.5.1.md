# v2.4 ~ v2.5.1：失败重试、并发控制与分析页重构

2026 年 8 月到 9 月，项目连续发布了 v2.4.0、v2.5.0、v2.5.1。三个版本的方向依次是：**运维安全 → 洞察与并发 → 性能与体验**。

## 1. v2.4.0（2026-08-20）：重试与 Cron 生成器

### 1.1 失败重试

作业编辑对话框的「调度设置」新增失败重试：

| 配置 | 范围 | 说明 |
| ---- | ---- | ---- |
| 重试次数 | 0–10 | 0 表示不重试 |
| 重试间隔 | 1–3600 秒 | 仅次数大于 0 时生效 |

由 `RetryJobWrapper` 在作业失败后按间隔重试，作业代码不需要自己写循环。

::: warning
重试只适合幂等作业。发消息、扣款、扣库存等操作请保持 0，或确保业务可重复执行。
:::

### 1.2 Cron 表达式生成器

- 秒、分、时、日、月、周逐项可视化配置；
- 支持常用模板；
- 输入时实时校验；
- 预览未来 10 次执行时间；
- 「日」和「周」互斥，设置一个后另一个自动切换为 `?`。

![Cron 生成器](/images/cron-helper.png)

### 1.3 其他

- 搜索条件自动保存，刷新不丢失；
- 列显示/隐藏设置持久化；
- 优化日志管理执行时间显示；
- 修复日志详情中作业数据的转义问题；
- 修复浏览器标题在会话过期后未加载。

## 2. v2.5.0（2026-08-30）：分析页与并发控制

### 2.1 分析页重构

新增/重做：

- 四张 KPI 卡片；
- 作业健康象限：成功率 × 平均耗时，气泡大小表示执行频次；
- 时段分布热力图：按星期与小时统计执行密度；
- 耗时 TOP 排行：平均、最大、最小耗时与最近执行时间。

![分析页](/images/analytices.png)

### 2.2 启用 / 禁用开关

作业列表新增 Switch，切换前弹出确认。它的语义是“是否参与调度”，与「暂停 / 恢复」不同：

- 禁用：退出调度，配置保留；
- 暂停：触发器暂停，作业仍在调度器中。

### 2.3 禁止并发执行

新增 `DisallowConcurrentExecution`：

- 字段落在作业实体与 DTO 中；
- 保存后由 Quartz 的 `JobBuilder` 自动应用；
- 四个数据库提供程序同步生成了迁移。

行为是：同一作业上一次执行未结束时，新的触发会等待上一次完成，而不是并发执行。适合执行时间可能超过调度间隔的作业。

> 数据库存储模式需要同步升级 EFCore 扩展包；启动时会自动应用迁移，不需要手动执行 `dotnet ef`。

### 2.4 作业对话框

- 新增 API 请求头 Key-Value 编辑器；
- 请求头支持常用头下拉与手动添加；
- 优化表单布局与交互；
- 统一对话框宽度为 800px；
- 日志 / 通知详情的查看图标改为 `info-circle-fill`。

![API 请求头编辑器](/images/job-api-headers.png)

### 2.5 修复

| 问题 | 处理 |
| ---- | ---- |
| 中英文切换后表头、搜索标签不更新 | 组件内改为响应式读取 i18n |
| 日志详情执行时长列过窄 | 调整列宽 |
| 系统设置英文 label 换行 | 调整标签宽度 |

## 3. v2.5.1（2026-09-04）：迁移可视化与性能

### 3.1 数据迁移可视化

从文件存储迁移到数据库时，不再只能看后端日志：

- 卡片式 UI；
- 时间线与进度条；
- 每一步的状态：等待、进行中、完成、失败、无数据；
- 迁移结束后给出汇总。

![数据迁移可视化](/images/migration-ui.png)

当前版本的迁移向导在此基础上继续扩展，支持五种存储互转，详见 [v2.6.0](/articles/15-v2.6.0)。

### 3.2 分析页性能优化

此前分析页会全量加载日志再在前端统计，数据量大时明显变慢。v2.5.1 改为：

- 查询在数据库侧聚合（`GroupBy`）；
- 统一使用 `AsNoTracking()`；
- 只取统计结果，不再加载完整日志。

### 3.3 修复

- 健康象限中大气泡遮挡小气泡，导致小气泡无法选中；
- 执行活跃度 / 质量 / 周同比按小时而非按天聚合。

## 4. 升级说明

### 4.1 更新包

```bash
dotnet add package Chet.QuartzNet.UI --version 2.5.1
```

数据库存储模式同步更新：

```bash
dotnet add package Chet.QuartzNet.EFCore.MySQL --version 2.5.1
dotnet add package Chet.QuartzNet.EFCore.PostgreSQL --version 2.5.1
dotnet add package Chet.QuartzNet.EFCore.SqlServer --version 2.5.1
dotnet add package Chet.QuartzNet.EFCore.SQLite --version 2.5.1
```

### 4.2 数据库结构

v2.4.0 增加了重试字段，v2.5.0 增加了并发控制字段。启动时 `MigrateAsync()` 会自动应用扩展包中的迁移，无需手动执行命令；生产环境仍建议先备份。

### 4.3 文件存储

旧 JSON 缺少新字段时使用默认值，无需处理。

## 5. 小结

| 版本 | 核心方向 | 关键能力 |
| ---- | -------- | -------- |
| v2.4.0 | 运维安全 | 失败重试、Cron 生成器、条件持久化 |
| v2.5.0 | 洞察 + 并发 | 分析页重构、象限图、热力图、并发控制、启用开关 |
| v2.5.1 | 性能体验 | 数据库侧聚合、迁移可视化、象限交互修复 |
