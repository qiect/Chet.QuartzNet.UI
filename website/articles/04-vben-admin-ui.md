# 基于 VbenAdmin 的界面体验

管理界面基于 **VbenAdmin**（Vue 3 + TypeScript + Vite + Ant Design Vue）。这部分不是简单的“套一层皮”，而是把主题、布局、国际化、列表交互这些通用能力直接带进了调度系统。

## 1. 技术栈与打包方式

| 项目 | 说明 |
| ---- | ---- |
| 前端框架 | Vue 3 + TypeScript |
| UI 组件 | Ant Design Vue |
| 管理框架 | VbenAdmin |
| 构建工具 | Vite |
| 打包方式 | 构建产物嵌入 RCL 的 `wwwroot`，随 NuGet 包发布 |

这意味着使用者无需单独部署前端，安装包后访问 `/quartz-ui` 即可；需要改界面时，则要修改 `src/Chet.QuartzNet.Web` 并重新构建。

## 2. 主题与外观

### 2.1 明暗模式

支持三种模式：

- **浅色**：默认；
- **深色**：适合夜间或低光环境；
- **跟随系统**：随操作系统切换。

深色模式下，分析页图表配色与热力图空格子已单独适配。

### 2.2 主题色

可在偏好设置中调整主色，导航、按钮、标签、图表配色会同步变化。

![登录界面](/images/login.png)

## 3. 布局

VbenAdmin 提供多种布局，可在运行时切换：

| 布局 | 特点 |
| ---- | ---- |
| 侧边导航 | 默认，左侧菜单 + 顶部栏 |
| 混合导航 | 顶部一级菜单 + 侧边子菜单 |
| 顶部导航 | 菜单全部在顶部 |
| 双列菜单 | 侧边两列，适合菜单较多的系统 |
| 全屏内容 | 隐藏菜单，只保留内容区 |

同时可调整：

- 菜单折叠与宽度；
- 顶部栏是否固定、是否显示面包屑；
- 标签页是否启用、是否可拖拽；
- 内容区宽度与内边距；
- 页脚固定与版权信息。

![分析页](/images/analytices.png)

## 4. 偏好设置

点击右上角设置按钮打开偏好面板，常用项包括：

| 分类 | 能力 |
| ---- | ---- |
| 外观 | 明暗模式、主题色、圆角、紧凑模式 |
| 布局 | 上述布局切换、侧边栏与顶栏行为 |
| 通用 | 水印、页面切换动画、色弱模式、灰色模式 |
| 快捷键 | 全局搜索、锁屏、退出登录的开关 |
| 国际化 | 中文 / English |

水印适合内网或演示环境，可配置内容与透明度；页面切换动画在低性能设备上可以关闭。

## 5. 中英文切换

界面文案通过 i18n 管理，覆盖分析、作业、日志、通知、系统设置等页面。切换语言后无需刷新，表格列头与搜索表单标签会同步更新。

## 6. 快捷键

默认启用的全局快捷键包括全局搜索、锁屏与退出登录，可在「偏好设置 → 快捷键」中查看当前组合并单独关闭。

## 7. 列表与表单交互

这部分是日常使用中感受最明显的：

- **服务端分页与排序**：作业、日志、通知列表基于 vxe-table，数据量大时不在前端堆积；
- **搜索条件持久化**：刷新或切换页面后保留筛选条件；
- **列设置持久化**：自定义显示列与列宽会被记住；
- **操作列悬停展开**：减少一次点击；
- **可拖拽弹窗**：作业编辑、日志详情等弹窗支持拖动；
- **二次确认**：启用/禁用、批量操作、清空日志、迁移等敏感操作都会确认。

![作业管理](/images/job.png)

## 8. 响应式与限制

- 桌面端为完整布局，窄屏下菜单折叠为抽屉；
- 页面以管理后台为主，未提供独立移动端 App；
- 前端是预构建产物，修改样式或页面需要重新构建并替换包内静态资源；
- 浏览器需支持现代 ES 特性，不支持 IE。

## 9. 二次开发提示

如果需要改前端：

```text
src/Chet.QuartzNet.Web/            # VbenAdmin 工程
├── apps/web-antd/src/views/quartz # 分析、作业、日志、通知、系统设置
├── packages/                       # 通用能力
└── internal/                       # 构建配置
```

构建后把产物同步到 `src/Chet.QuartzNet.UI/wwwroot`，再重新打包 NuGet。仅改后端配置时不需要动前端。
