# 日志管理介绍

日志页不只用来“看记录”，也是处理异常记录的入口：筛选、看详情、对中断记录重新执行，以及配置日志保留策略都在这里完成。

![日志管理](/images/log.png)

## 1. 一条日志包含什么

| 字段 | 说明 |
| ---- | ---- |
| 作业名称 / 分组 | 归属 |
| 状态 | 运行中、成功、失败、已跳过、中断 |
| 开始时间 / 结束时间 | 执行区间 |
| 执行时长 | 列表以秒展示，详情展示完整时长 |
| 触发来源 | 定时、手动、补偿重跑 |
| 执行消息 | 作业写入的结果说明 |
| 错误信息 / 异常 | 失败时的错误码与堆栈 |
| 作业数据 | 执行时的参数快照，支持格式化与复制 |
| 恢复信息 | 最后心跳、补偿状态、跳过原因等 |

## 2. 五种状态

| 状态 | 含义 | 常见原因 |
| ---- | ---- | -------- |
| 运行中 | 已开始、尚未结束 | 正在执行，或进程已崩溃但尚未判定 |
| 成功 | 正常结束 | — |
| 失败 | 抛出异常或返回失败 | 业务异常、接口报错、超时 |
| 已跳过 | 本次未执行 | 前置依赖未满足 |
| 中断 | 未正常收尾 | 进程崩溃、强杀、停机超时 |

「中断」与「失败」不同：失败是作业自己报错，中断是执行过程被外部终止，记录停在 `Running`，由心跳超时判定。

## 3. 查询与筛选

- 按作业名称、分组搜索；
- 按状态筛选（五种状态）；
- 分别按「开始时间范围」与「结束时间范围」筛选；
- **仅看异常**：只显示失败 + 中断，开启后忽略状态筛选；
- 服务端分页与排序，搜索条件与列设置持久化。

「触发来源」可以帮助区分问题来源：

| 来源 | 说明 |
| ---- | ---- |
| 定时 | Cron 正常触发 |
| 手动 | 点击「立即执行」或「重新执行」 |
| 补偿重跑 | 中断后由补偿机制触发，可追溯到源记录 |

## 4. 日志详情

![日志详情](/images/log-detail.png)

详情弹窗包含：

- 顶部状态色条（成功 / 失败 / 运行中 / 等待 / 中断）；
- 作业、分组、时间、耗时、触发来源等元数据；
- 执行信息与执行结果；
- 错误信息与异常堆栈（可折叠）；
- 作业数据（JSON 可格式化、复制）；
- 中断记录的恢复信息：最后心跳、失联时长、补偿状态、跳过原因。

## 5. 中断记录的「重新执行」

只有中断状态的行会显示「重新执行」按钮。

- 提交前会提示：将整段重跑，耗时约等于原任务，可能产生重复副作用；
- 已补偿过、作业已停用或已暂停、调度器未运行时，会直接拒绝并提示原因；
- 重跑会产生一条新日志，触发来源为「补偿重跑」，并指回原中断记录；源记录保留。

::: warning
补偿与重跑都是 at-least-once。非幂等作业（发消息、扣款、扣库存）应先确认业务幂等，或在作业上关闭「中断后自动重跑」。
:::

## 6. 清空日志

点击「清空日志」会删除当前存储中的执行记录，操作不可恢复。如果包含中断记录，界面会额外提示：清空后这些执行不会再被自动补偿。

需要保留排查线索时，不要直接清空，先按时间范围筛选后确认影响范围。

## 7. 日志配置

点击「日志配置」可直接修改保留策略，无需再去系统设置页：

| 配置项 | 默认值 | 说明 |
| ------ | ------ | ---- |
| 启用自动清理 | 开启 | 关闭后只能手动清空 |
| 保留天数 | 30 | 超过天数自动清理，0 = 不按天数清理 |
| 最大保留条数 | 0 | 总数超过后按时间倒序删除最旧记录，0 = 不限 |
| 清理间隔 | 6 小时 | 后台任务周期，范围 1–168 小时 |

后台清理服务在应用启动 60 秒后开始工作，之后按配置间隔循环执行，日志中会输出清理结果：

```text
[作业日志自动清理] 清理完成，共清理 153 条日志，下次清理间隔 6 小时
```

两种策略可以同时生效：先按天数删除过期记录，再按条数删除溢出部分。待补偿的中断记录不会被自动清理。

## 8. 排查流程

推荐按下面顺序处理一次失败：

1. 打开「仅看异常」，把失败与中断筛出来；
2. 先看时间分布：是集中爆发还是零散失败；
3. 打开详情，阅读错误信息与异常堆栈；
4. 对照作业数据，确认入参是否符合预期；
5. 若为中断，查看最后心跳与补偿状态，决定是否重新执行；
6. 修复后手动执行一次，确认新日志为成功。

### 常见模式

| 现象 | 可能原因 |
| ---- | -------- |
| 同一时段多条失败 | 依赖服务不可用、数据库连接数不足 |
| 单条耗时接近调度间隔 | 任务过重，考虑拆分或开启禁止并发 |
| 大量「已跳过」 | 前置依赖作业失败或未执行 |
| 运行中长时间不结束 | 任务卡住、外部接口无超时 |
| 中断记录集中出现 | 发布重启、容器被回收、强杀进程 |

## 9. 页面没有提供的功能

- 不支持导出 Excel / CSV；
- 不支持对日志内容做全文搜索（只按作业名称、分组、状态、时间筛选）；
- 不提供按作业维度的统计报表（统计在分析页）；
- 日志清理没有“立即执行一次”的按钮，由后台任务按间隔执行。
