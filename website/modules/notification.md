# 通知管理

通知管理用于配置作业成功 / 失败与调度器异常的消息推送，并保留完整的发送历史。

![通知管理](/images/notification.png)

## 1. 页面构成

| 区域 | 说明 |
| --- | --- |
| 通知配置 | PushPlus Token、渠道、模板、主题 |
| 通知策略 | 成功、失败、调度器异常是否发送 |
| 通知列表 | 发送历史、状态、耗时 |
| 操作 | 测试通知、删除、清空 |

## 2. 通知配置

点击「通知配置」填写：

| 配置项 | 说明 |
| --- | --- |
| 启用通知 | 总开关 |
| Token | PushPlus 个人 Token |
| 推送渠道 | 微信 / 企业微信 / 钉钉 / 邮件等 |
| 消息模板 | HTML / Markdown / 纯文本 |
| 主题 | 通知主题（可选） |

配置步骤与 PushPlus 注册见 [通知配置](/guide/notification)。

## 3. 通知策略

| 策略 | 默认 |
| --- | --- |
| 作业成功时发送 | 关闭 |
| 作业失败时发送 | 开启 |
| 调度器异常时发送 | 开启 |

## 4. 通知历史

列表展示：

- 通知标题；
- 触发来源（作业或调度器）；
- 状态：待发送 / 发送成功 / 发送失败；
- 创建时间、发送时间、耗时；
- 失败原因。

支持按状态筛选、按来源搜索、单条删除与批量清空。

![通知详情](/images/notification-detail.png)

![微信推送效果](/images/wechat-notification-pushplus.png)

## 5. 测试通知

配置完成后点击「发送测试通知」验证。若失败：

- 检查 Token 是否有效；
- 检查网络是否能访问 PushPlus；
- 检查推送渠道与模板是否兼容；
- 查看通知历史中的错误信息。

## 6. 建议

- 必须开启失败与调度器异常通知；
- 成功通知按需开启，避免噪声；
- 每次修改配置后发送测试；
- 定期清理历史，避免数据无限增长。
