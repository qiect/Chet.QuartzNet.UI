# 分析页

分析页是登录后的默认工作台，用于回答四个问题：**有多少作业、调度器当前是否正常、执行质量如何、哪里可能有风险。**

![分析页](/images/analytices.png)

## 1. 页面构成

| 区域 | 内容 |
| --- | --- |
| 顶部 | 服务标识：服务名称、环境标识、服务描述 |
| KPI 区 | 作业总览、调度运行态、执行质量、风险巡检 |
| 趋势 | 执行趋势（整行） |
| 分析区 | 作业健康象限、时段分布热力图（左右并排） |
| 排行 | 耗时 TOP 排行 |

## 2. KPI 卡片

### 2.1 作业总览

- 作业总数；
- 启用 / 禁用数量；
- 正常 / 暂停数量；
- 环形图展示启用占比。

用于确认配置层面是否正常，例如发布后是否有一批作业被误禁用。

### 2.2 调度运行态

| 指标 | 说明 |
| --- | --- |
| 执行中任务数 | 当前正在执行的任务数量 |
| 线程槽位 | 已占用槽位与线程池上限 |
| 调度器状态 | 运行中 / 待机 / 排水中 / 已停止 |
| 运行时长 | 自调度器启动以来的时间 |
| 待补偿数 | 尚未处理的中断记录数 |

该卡片按 **5 秒**轮询刷新，页面不可见时暂停轮询。

### 2.3 执行质量

- 近 7 日成功率（环形图）；
- 近 7 日成功数与失败数。

成功率下降但失败数不多时，往往是执行总量变小导致的，需要结合趋势图判断。

### 2.4 风险巡检

- 指标值 = 沉默作业数 + 风险作业数；
- **沉默作业**：已启用、未暂停，但统计窗口内没有任何执行记录；
- **风险作业**：成功率低于 95% 且有失败记录；
- 卡片底部展示沉默作业数量与失败最多的作业。

沉默作业常见于 Cron 写错、触发器未生效、作业被禁用后又启用。周级、月级低频任务可能被误判，需要结合业务周期看。

## 3. 图表与分析方法

### 3.1 执行趋势

按天展示总执行数、成功数、失败数与成功率。失败曲线上会用 2σ 规则标出异常日，图表上方给出日环比与异常日数量。

### 3.2 作业健康象限

- 横轴：成功率（阈值 80%）；
- 纵轴：平均耗时（阈值取所有作业耗时的中位数）；
- 气泡大小：执行次数；
- 气泡颜色：作业状态。

| 象限 | 含义 | 建议 |
| --- | --- | --- |
| 高成功率 · 低耗时 | 健康 | 保持 |
| 高成功率 · 高耗时 | 稳定但慢 | 关注资源占用与超时设置 |
| 低成功率 · 低耗时 | 快速失败 | 多为配置或依赖问题，优先排查 |
| 低成功率 · 高耗时 | 高风险 | 优先处理，可能拖垮线程池 |

气泡支持选中，避免大点遮挡小点时无法操作。

### 3.3 时段分布热力图

按**星期 × 小时**统计执行次数，颜色越深表示越密集。用于：

- 发现任务扎堆的时段；
- 调整 Cron 错峰，避免整点集中触发；
- 判断是否存在长期空档。

空白格子表示该时段没有执行记录，深色主题下已单独适配。

### 3.4 耗时 TOP 排行

列出平均耗时、最大耗时、最小耗时与最近执行时间，是性能优化的入口。耗时长期接近调度间隔的作业，应考虑拆分或异步化。

## 4. 数据范围与性能

- 页面**没有时间范围选择控件**，统计窗口由后端查询参数决定；前端未指定时使用后端默认窗口；
- 后端支持今日、昨日、本周、本月、近 30 天等参数，通过 API 调用时可以指定；
- 运行态数据来自当前调度器实例，多实例部署时只反映当前节点。

数据库存储模式下，统计查询在数据库侧聚合（`GroupBy`）并使用 `AsNoTracking()`，不会把日志全量加载到内存；文件存储模式为内存聚合，日志量大时建议切换数据库存储。

## 5. 使用建议

1. 每天先看失败率、待补偿数与健康象限，定位异常作业；
2. 结合热力图调整 Cron，避免整点集中触发；
3. 对耗时 TOP 作业做拆分或异步化；
4. 多环境部署时为每个实例设置清晰的服务标识；
5. 低频任务被标为「沉默作业」时，人工确认 Cron 与业务周期。
