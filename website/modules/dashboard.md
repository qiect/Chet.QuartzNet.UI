# 分析页

分析页是登录后的默认工作台，用于快速判断调度系统整体是否健康。

![分析页](/images/analytices.png)

## 1. 页面构成

### 1.1 KPI 卡片

展示关键指标：

- 作业总数；
- 启用 / 禁用作业数；
- 正在执行作业数；
- 成功 / 失败执行次数；
- 近期成功率等。

### 1.2 作业健康象限

按**执行频率**与**成功率**把作业划分到四个象限，快速识别：

- 高频且高成功：稳定的核心作业；
- 高频但低成功：需要优先排查；
- 低频且低成功：可能是配置或依赖问题；
- 低频且高成功：正常的长周期任务。

象限图支持气泡选中，避免大点遮挡小点。

### 1.3 时段分布热力图

展示一天中各时段的作业执行密度，用于：

- 发现任务扎堆的时段；
- 调整 Cron 分散压力；
- 判断是否存在调度空档。

### 1.4 耗时 Top 排名

按执行耗时对作业排序，快速定位性能瓶颈。

### 1.5 服务标识

页面顶部展示「系统配置」中设置的服务名称、环境标识与描述，多实例部署时可以区分环境。

## 2. 数据范围

- 默认统计近 30 天数据；
- 日期范围可调整；
- 图表随筛选条件刷新。

## 3. 性能说明

v2.5.1 起，分析页查询改为数据库侧聚合（`GroupBy`）并禁用 EF Core 变更跟踪（`AsNoTracking`），避免全量加载日志导致的性能问题。

## 4. 使用建议

1. 每天先看失败率与健康象限，定位异常作业；
2. 结合热力图调整 Cron，避免整点集中触发；
3. 对耗时 Top 作业做拆分或异步化；
4. 多环境部署时为每个实例设置清晰的服务标识。
