# 日志管理

日志页记录每次执行的完整过程，是排查失败、识别中断与优化耗时的主要入口。

![日志管理](/images/log.png)

## 1. 日志内容

| 字段 | 说明 |
| --- | --- |
| 作业名称 / 分组 | 归属 |
| 状态 | 运行中、成功、失败、已跳过、中断 |
| 开始时间 / 结束时间 | 执行区间 |
| 执行时长 | 列表按秒展示，详情展示完整时长 |
| 触发来源 | 定时、手动、补偿重跑 |
| 执行消息 | 作业写入的结果说明 |
| 错误信息 / 异常 | 失败时的错误码与堆栈 |
| 作业数据 | 执行参数快照，支持格式化与复制 |
| 恢复信息 | 最后心跳、补偿状态、跳过原因等 |

## 2. 五种状态

| 状态 | 含义 | 常见原因 |
| --- | --- | --- |
| 运行中 | 已开始、尚未结束 | 正在执行，或崩溃后尚未判定 |
| 成功 | 正常结束 | — |
| 失败 | 抛出异常或返回失败 | 业务异常、接口报错、超时 |
| 已跳过 | 本次未执行 | 前置依赖未满足 |
| 中断 | 未正常收尾 | 进程崩溃、强杀、停机超时 |

「中断」不是「失败」：失败由作业自身报错，中断是执行过程被外部终止，记录停在运行中，由心跳超时判定。

## 3. 查询与筛选

- 按作业名称、分组搜索；
- 按状态筛选；
- 分别按「开始时间范围」与「结束时间范围」筛选；
- **仅看异常**：只显示失败与中断，开启后忽略状态筛选；
- 服务端分页与排序；
- 搜索条件、排序状态与列设置持久化。

「触发来源」用于区分问题来源：

| 来源 | 说明 |
| --- | --- |
| 定时 | Cron 正常触发 |
| 手动 | 「立即执行」 |
| 补偿重跑 | 中断恢复或手动重新执行，可追溯到源记录 |

## 4. 日志详情

![日志详情](/images/log-detail.png)

- 顶部状态色条标识结果；
- 元数据区展示作业、分组、时间、耗时与触发来源；
- 执行信息与执行结果；
- 错误信息与异常堆栈，可折叠查看；
- 作业数据支持 JSON 格式化与复制；
- 中断记录额外展示最后心跳、补偿状态与跳过原因。

## 5. 已跳过

依赖不满足时写入「已跳过」日志，并在消息中说明原因：

```text
前置依赖未满足，本次执行已跳过：
demo.job-a 最近一次执行状态为 Failed
```

可在状态筛选中单独查看，用于定位被依赖卡住的任务。详见 [作业依赖](/guide/dependency)。

## 6. 中断与重新执行

中断记录来自进程崩溃、强杀或停机超时：

- 展示最后心跳与补偿状态；
- 若已自动补偿，「触发来源」显示「补偿重跑」，可回看原执行；
- 仅中断行提供「重新执行」，提交前提示会整段重跑。

重新执行前会校验：

- 记录必须是中断状态且未补偿；
- 作业必须启用且未暂停；
- 调度器必须处于运行状态。

不满足时直接拒绝并提示原因。补偿规则与语义边界见 [中断恢复与排水调度](/guide/recovery)。

## 7. 日志配置

点击「日志配置」直接修改保留策略：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 启用自动清理 | 开启 | 关闭后置零两条限制，只能手动清理 |
| 保留天数 | 30 | 超过天数自动清理，0 = 不限制 |
| 最大保留条数 | 0 | 总数超过后删除最旧日志，0 = 不限 |
| 清理间隔（小时） | 6 | 后台任务周期，1–168 |

后台服务在应用启动 60 秒后开始工作，按间隔循环执行；按天数与按条数可以同时生效。

```text
[作业日志自动清理] 清理完成，共清理 153 条日志，下次清理间隔 6 小时
```

待补偿的中断记录（未补偿或补偿待处理）不会被按天数或按条数清理，避免丢失恢复依据。

## 8. 排查建议

1. 开启「仅看异常」，筛出失败与中断；
2. 看时间分布：集中爆发还是零散失败；
3. 打开详情阅读错误信息与异常堆栈；
4. 对照作业数据确认入参；
5. 中断记录先看最后心跳与补偿状态，再决定是否重新执行；
6. 修复后手动执行一次，确认新日志为成功。

| 现象 | 可能原因 |
| --- | --- |
| 同时段多条失败 | 依赖服务不可用、连接数不足 |
| 耗时接近调度间隔 | 任务过重，考虑拆分或开启禁止并发 |
| 大量「已跳过」 | 前置依赖失败或未执行 |
| 长时间运行中 | 任务卡住、外部接口无超时 |
| 中断集中出现 | 发布重启、容器回收、强杀进程 |

## 9. 页面边界

- 不支持导出 Excel / CSV；
- 不支持日志内容全文搜索；
- 不提供按作业维度的统计报表；
- 日志清理没有「立即执行一次」按钮，由后台任务按间隔执行。
