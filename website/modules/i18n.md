# 多语言与主题

界面基于 VbenAdmin，国际化、主题与布局都通过统一的偏好设置管理。

## 1. 中英文切换

支持简体中文与英文，覆盖：

- 菜单与页面标题；
- 表格列头与分页文案；
- 搜索表单标签；
- 按钮、提示与校验消息；
- 作业编辑、通知配置等表单。

![语言切换](/images/i18n-switch.png)

![英文界面 - 作业](/images/i18n-job-en.png)

![中文界面 - 作业](/images/i18n-job-zh.png)

切换后无需刷新，列头与表单标签同步更新。语言偏好保存在浏览器本地，默认 `zh-CN`。

## 2. 主题

| 模式 | 说明 |
| --- | --- |
| 浅色 | 默认 |
| 深色 | 夜间或低光环境 |
| 跟随系统 | 随操作系统切换 |

深色模式下，分析页图表配色与热力图空格子已单独适配。主题色、圆角、紧凑模式可在偏好设置中调整。

## 3. 布局

可在运行时切换：

| 布局 | 特点 |
| --- | --- |
| 侧边导航 | 左侧菜单 + 顶部栏，默认 |
| 混合导航 | 顶部一级菜单 + 侧边子菜单 |
| 顶部导航 | 菜单全部在顶部 |
| 双列菜单 | 侧边两列，适合菜单较多 |
| 全屏内容 | 隐藏菜单，只保留内容区 |

还可以调整菜单折叠、标签页、面包屑、页脚固定、内容区宽度与内边距。

## 4. 偏好设置

点击右上角设置按钮打开偏好面板：

| 分类 | 能力 |
| --- | --- |
| 外观 | 明暗模式、主题色、圆角、紧凑模式 |
| 布局 | 布局切换、侧边栏与顶栏行为 |
| 通用 | 水印、页面切换动画、色弱模式、灰色模式 |
| 快捷键 | 各全局快捷键的开关 |
| 国际化 | 中文 / English |

水印可配置内容与透明度，适合内网或演示环境；页面动画在低性能设备上可以关闭。

## 5. 快捷键

默认启用的全局快捷键：

| 功能 | 说明 |
| --- | --- |
| 全局搜索 | 打开菜单搜索 |
| 锁屏 | 立即锁定界面 |
| 退出登录 | 清除登录态并返回登录页 |
| 偏好设置 | 打开设置面板 |

可在偏好设置的「快捷键」中查看当前组合并单独关闭。

## 6. 响应式与限制

- 窄屏下侧边菜单折叠为抽屉；
- 表格在窄屏下横向滚动，可配合列设置精简显示；
- 界面面向桌面管理后台，未提供独立移动端 App；
- 浏览器需支持现代 ES 特性，不支持 IE。
