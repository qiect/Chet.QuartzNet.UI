# 多语言与主题

管理界面基于 VbenAdmin，内置国际化与主题偏好能力。

## 1. 中英文切换

界面支持简体中文与英文切换，覆盖：

- 菜单与页面标题；
- 表格列头；
- 搜索表单标签；
- 操作按钮与提示信息；
- 作业编辑表单。

![语言切换](/images/i18n-switch.png)

![英文界面 - 作业](/images/i18n-job-en.png)

![中文界面 - 作业](/images/i18n-job-zh.png)

切换后无需刷新页面，表格列头与表单标签会同步更新。语言偏好保存在浏览器本地。

## 2. 主题模式

- 浅色模式；
- 深色模式；
- 跟随系统。

主题基于 VbenAdmin 的偏好设置，切换后立即生效。

## 3. 偏好设置

可在界面右上角的偏好设置面板中调整：

| 设置 | 说明 |
| --- | --- |
| 主题 | 浅色 / 深色 / 跟随系统 |
| 主题色 | 界面主色调 |
| 布局 | 侧边栏、顶栏、混合布局 |
| 菜单 | 折叠、手风琴等 |
| 底栏 | 是否显示底栏与版权 |
| 水印 | 页面水印内容 |
| 页面动画 | 切换动画开关 |

## 4. 快捷键

VbenAdmin 内置常用快捷键，例如：

- 全局搜索；
- 侧边栏折叠；
- 退出登录；
- 刷新页面。

具体组合以界面「快捷键」面板展示为准。

## 5. 响应式与移动端

界面支持响应式布局，移动端可访问核心页面。复杂表格在窄屏下建议使用横向滚动或列设置精简列。
