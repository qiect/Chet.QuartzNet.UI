# 模块总览

管理界面基于 VbenAdmin，默认入口 `/quartz-ui`。登录后左侧菜单包含以下模块：

| 模块 | 主要能力 | 文档 |
| --- | --- | --- |
| 分析页 | KPI、健康象限、热力图、耗时排行 | [分析页](/modules/dashboard) |
| 作业管理 | 增删改查、启停、批量操作、依赖、重试 | [作业管理](/modules/job) |
| 日志管理 | 执行历史、状态筛选、详情、自动清理 | [日志管理](/modules/log) |
| 通知管理 | PushPlus 配置、策略、历史、测试 | [通知管理](/modules/notification) |
| 系统配置 | 服务标识、日志清理、数据迁移 | [系统配置](/modules/system-config) |
| 多语言 / 主题 | 中英文、浅色 / 深色主题、偏好设置 | [多语言与主题](/modules/i18n) |

## 界面通用能力

- **服务端分页与排序**：作业、日志、通知列表基于 vxe-table，支持大数据量；
- **搜索条件持久化**：刷新或切换页面后保留筛选条件；
- **列设置持久化**：自定义列显示后自动记忆；
- **响应式布局**：支持桌面与移动端访问；
- **主题切换**：浅色 / 深色主题随系统或手动切换；
- **可拖拽对话框**：作业编辑、详情等弹窗支持拖拽；
- **操作确认**：启用 / 禁用、批量操作、数据迁移等敏感操作均有二次确认。

## 典型使用路径

```text
登录 → 分析页查看整体健康度
     → 作业管理创建 / 调整作业
     → 日志管理排查失败
     → 通知管理确认告警是否送达
     → 系统配置调整日志保留与迁移
```

## 访问与认证

- 地址：`/quartz-ui`
- 账号：`QuartzUI:UserName` / `QuartzUI:Password`
- 认证：JWT，Token 过期后自动跳转登录

配置见 [配置说明](/guide/configuration)。
