# 模块总览

管理界面基于 VbenAdmin，默认入口 `/quartz-ui`。登录后左侧菜单包含以下模块：

| 模块 | 主要能力 | 文档 |
| --- | --- | --- |
| 分析页 | KPI、健康象限、热力图、耗时排行 | [分析页](/modules/dashboard) |
| 作业管理 | 增删改查、启停、批量操作、依赖、重试、排水 | [作业管理](/modules/job) |
| 日志管理 | 执行历史、异常筛选、中断重跑、日志配置 | [日志管理](/modules/log) |
| 通知管理 | PushPlus 配置、策略、模板、历史与测试 | [通知管理](/modules/notification) |
| 系统配置 | 服务标识、停机与恢复、数据迁移 | [系统配置](/modules/system-config) |
| 通用能力 | 中英文、主题、布局、偏好设置 | [多语言与主题](/modules/i18n) |

## 1. 可靠性能力入口（v2.7）

| 能力 | 入口 | 说明 |
| --- | --- | --- |
| 中断识别与自动补偿 | 系统配置 → 停机与恢复 | 心跳超时判定中断，启动后按策略补跑 |
| 中断记录重新执行 | 日志管理 → 中断行「重新执行」 | 整段重跑，可回溯补偿来源 |
| 排水 / 停止 / 恢复调度 | 作业管理顶部状态条 | 停接新触发、等待收尾、超时可恢复 |
| 作业级中断补跑 | 作业管理 → 编辑 → 中断补跑 | 跟随全局 / 开启 / 关闭三态 |
| 日志保留与清理 | 日志管理 → 日志配置 | 待补偿的中断记录受保护 |

完整语义与操作步骤见 [中断恢复与排水调度](/guide/recovery)。

## 2. 界面通用能力

- **服务端分页与排序**：作业、日志、通知列表基于 vxe-table，翻页与排序走后端；
- **条件持久化**：搜索条件、排序状态与列设置保存在浏览器本地，刷新后保留；
- **操作列悬停展开**：减少列表行内的常驻按钮；
- **可拖拽对话框**：作业编辑、日志详情、通知详情等支持拖动；
- **操作确认**：启用 / 禁用、批量操作、清空日志、数据迁移等均有二次确认；
- **窄屏适配**：菜单折叠为抽屉，表格可横向滚动，页面以桌面管理后台为主。

## 3. 典型使用路径

```text
登录 → 分析页查看整体健康度
     → 作业管理创建 / 调整作业
     → 日志管理排查失败与中断
     → 通知管理确认告警配置与送达
     → 系统配置调整停机恢复策略或迁移存储
```

## 4. 访问与认证

- 地址：`/quartz-ui`
- 账号：`QuartzUI:UserName` / `QuartzUI:Password`
- 认证：内置 JWT，Token 过期后跳转登录页

配置见 [配置说明](/guide/configuration)。
