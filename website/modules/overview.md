# 模块总览

管理界面基于 VbenAdmin，默认入口 `/quartz-ui`。登录后左侧菜单包含以下模块：

| 模块 | 主要能力 | 文档 |
| --- | --- | --- |
| 分析页 | KPI、健康象限、热力图、耗时排行 | [分析页](/modules/dashboard) |
| 作业管理 | 增删改查、启停、批量操作、依赖、重试、排水 | [作业管理](/modules/job) |
| 日志管理 | 执行历史、状态筛选、中断重跑、日志配置 | [日志管理](/modules/log) |
| 通知管理 | PushPlus 配置、策略、历史、测试 | [通知管理](/modules/notification) |
| 系统配置 | 服务标识、停机与恢复、数据迁移 | [系统配置](/modules/system-config) |
| 多语言 / 主题 | 中英文、浅色 / 深色主题、偏好设置 | [多语言与主题](/modules/i18n) |

## 可靠性能力入口（v2.7）

| 能力 | 入口 | 说明 |
| --- | --- | --- |
| 中断识别与自动补偿 | 系统配置 → 停机与恢复 | 心跳超时判定中断，启动按策略补跑；启动后弹出恢复汇总 |
| 中断记录重新执行 | 日志管理 → 中断行「重新执行」 | 整段重跑，可回溯补偿来源 |
| 排水 / 停止 / 恢复调度 | 作业管理顶部状态条 | 停接新触发、等待收尾、超时可恢复 |
| 作业级自动重跑 | 作业管理 → 编辑 → 中断后自动重跑 | 跟随全局 / 开启 / 关闭三态 |
| 日志保留与清理 | 日志管理 → 日志配置 | 待补偿的中断记录不会被清理 |

完整语义与操作步骤见 [中断恢复与排水调度](/guide/recovery)。

## 界面通用能力

- **服务端分页与排序**：作业、日志、通知列表基于 vxe-table，支持大数据量；
- **搜索条件持久化**：刷新或切换页面后保留筛选条件；
- **列设置持久化**：自定义列显示后自动记忆；
- **响应式布局**：支持桌面与移动端访问；
- **主题切换**：浅色 / 深色主题随系统或手动切换；
- **可拖拽对话框**：作业编辑、详情等弹窗支持拖拽；
- **操作确认**：启用 / 禁用、批量操作、数据迁移等敏感操作均有二次确认。

## 典型使用路径

```text
登录 → 分析页查看整体健康度
     → 作业管理创建 / 调整作业
     → 日志管理排查失败
     → 通知管理确认告警是否送达
     → 系统配置调整日志保留与迁移
```

## 访问与认证

- 地址：`/quartz-ui`
- 账号：`QuartzUI:UserName` / `QuartzUI:Password`
- 认证：JWT，Token 过期后自动跳转登录

配置见 [配置说明](/guide/configuration)。
