# 更新日志

> 版本号与 NuGet 包版本保持一致。数据库存储模式升级时，请同步更新对应的 EFCore 扩展包并执行数据库迁移。

## 2.6.0 · 2026-11-03

**新增**

- **作业依赖（工作流）**：作业可配置一个或多个前置依赖作业，触发前校验依赖作业最近一次执行是否成功；未满足则本次跳过并记录「已跳过」日志。保存时自动校验自依赖、依赖不存在与循环依赖。
- **批量操作**：作业列表支持多选后批量暂停 / 恢复 / 启用 / 禁用。
- **日志自动清理**：系统配置新增日志保留天数（默认 30 天）、最大条数与清理间隔，后台定时清理历史日志。
- **存储数据迁移**：文件 / MySQL / PostgreSQL / SQLite / SQL Server 五种存储任意互转，支持作业、日志、系统设置与通知；提供预检、进度轮询、合并 / 覆盖 / 替换三种写入模式与迁移后校验。

**优化**

- 日志管理新增「已跳过」状态展示与筛选。
- 数据迁移同步复制作业依赖字段。

**兼容性**

- 与 .NET 8.0 / 10.0 完全兼容。
- 数据库存储模式需同步更新 EFCore 扩展包并执行迁移（新增 `Dependencies` 字段）。

## 2.5.1 · 2026-09-04

**新增**

- 数据迁移可视化：文件存储到数据库存储的可视化迁移，卡片式 UI + 时间线 + 进度条，实时展示迁移进度。

**优化**

- 分析页查询改为数据库侧聚合（`GroupBy`）并禁用 EF Core 变更跟踪（`AsNoTracking`），消除全量加载日志的性能问题。
- 修复健康象限图大气泡覆盖小气泡无法选中的问题，优化交互。

**修复**

- 修复执行活跃度 / 质量 / 周同比数据基于小时而非天聚合的问题。

## 2.5.0 · 2026-08-30

**新增**

- 重构分析页：KPI 卡片、作业健康象限、时段分布热力图、耗时 Top 排名。
- 作业管理支持启用 / 禁用开关，切换前弹出确认。
- 作业对话框新增 API 请求头 Key-Value 对编辑器。
- 新增「禁止并发执行」（`DisallowConcurrentExecution`），四个数据库提供程序同步迁移。

**优化**

- 优化作业编辑表单布局与交互。
- 统一对话框宽度为 800px。

**修复**

- 修复中英文切换后表格列头、搜索表单标签不更新。
- 修复日志详情执行时长列过窄。
- 修复系统设置表单英文 label 换行。

## 2.3.0 · 2026-07-15

**新增**

- 日志多条件查询：支持开始 / 结束时间范围筛选（ISO 8601）。
- 分析页重写：图表重构 + 顶部服务标识 + KPI 卡片图标优化。

**优化**

- 详情对话框：状态色条 + Descriptions 元数据 + 简化 header。
- 作业编辑页分区布局。
- 所有 Modal 支持拖拽，vxe-table 排序状态持久化。
- 作业操作列改为 hover 触发，时长列改为秒显示。
