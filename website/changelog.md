# 更新日志

> 版本号与 NuGet 包版本保持一致。数据库存储模式升级时，请同步更新对应的 EFCore 扩展包并执行数据库迁移。

## 2.7.0 · 2026-11-14

**新增**

- **执行日志生命周期重构**：执行开始即写入 `Running` 日志并注册到执行表，结束后更新同一条记录；新增心跳续期，页面可看到运行中任务与实时耗时。
- **中断识别与自动补偿**：心跳超时（租约默认 60 秒）后标记「中断」，下次启动按策略自动补跑；支持只标记 / 补最近一次 / 全部补偿，最大执行次数与临近触发跳过阈值可配。
- **手动重新执行**：日志列表的中断记录支持一键重跑，重复提交返回冲突而不报错。
- **启动恢复提示**：应用启动后提示「检测到 N 个中断执行，已重跑 X / 跳过 Y / 失败 Z」，按启动标识去重。
- **排水调度**：停止接收新触发、等待执行中任务收尾后自动停止，超时标记中断；排水未完成时可「恢复调度」。
- **优雅停机策略**：新增停机模式（立即停止 / 排水后停止）与排水超时配置。
- **停机与恢复配置组**：系统配置页新增独立分区，展示生效方式与「重启后生效 N 项」旧值 / 新值明细。
- **作业级自动重跑**：作业支持「跟随全局 / 开启 / 关闭」三态配置，列表显示对应图标。
- **JSON 消息模板**：作业执行、调度器异常与测试通知均按所选模板输出结构化 JSON。

**优化**

- 分析页 KPI 卡片重构为「作业总览 / 调度运行态 / 执行质量 / 风险巡检」，运行态按 5 秒轮询刷新，风险巡检展示沉默作业与失败 TOP。
- 日志页新增「中断」状态、「触发来源」列、「仅看异常」筛选与恢复信息详情；日志清理配置迁移至日志页，可直接查看当前日志总量。
- 通知配置页消息模板改为卡片式选择器，新增 HTML / Markdown / TXT / JSON 实时推送预览，模板预览改为悬停浮层。
- 系统配置页分区导航与布局优化，强化环境标识展示；数据迁移的预检结果与迁移摘要统一改为弹窗，仅一种存储时给出空状态提示。
- 文件存储并发优化：读不加锁、写临时文件原子替换，读改写收敛到单锁区间。
- SQLite 启用 WAL 与 `busy_timeout`，页面查询不再被作业写入阻塞。
- 分析页与列表查询统一 `AsNoTracking`，清空日志改用 `ExecuteDelete`。
- 作业类名与 API 地址拆分为独立字段，切换作业类型不再互相带值。
- 通知模板兼容历史配置的模板格式与通知策略缺失场景。

**修复**

- 修复中断日志误判与重试状态显示错误。
- 修复排水状态残留，统一停机策略（`Wait` 作为 `Drain` 的兼容别名）。
- 修复作业 / 日志列表搜索后表头排序标识丢失。
- 修复日志详情执行时长换行错位。
- 修复配置与数据迁移把中文写成 Unicode 转义。
- 修复 API 作业响应未释放、调度器启动时间取值恒为空。
- 修复分析页执行趋势统计口径（按天聚合）与筛选切换的请求竞态。
- 修复表格列设置持久化失效。

**其他**

- 分析页图表适配深色主题，补齐热力图空格子。
- CI 拆分站点部署与 NuGet 发布两个工作流，NuGet 发布改用 Trusted Publishing (OIDC)。
- 示例项目补充 CORS、线程池与类作业自动注册示例。

**兼容性**

- 与 .NET 8.0 / 10.0 完全兼容。
- 数据库存储模式需同步更新 EFCore 扩展包并执行迁移（新增 `AddRecoveryAndDrainFields`，包含作业重跑字段与日志恢复字段）。
- 新列全部可空或有默认值，老库可直接升级；回滚旧版本后中断记录仍可见，但旧版本不会补偿。
- 补偿语义为 at-least-once，非幂等作业请在作业上关闭「中断后自动重跑」。

## 2.6.0 · 2026-11-03

**新增**

- **作业依赖（工作流）**：作业可配置一个或多个前置依赖作业，触发前校验依赖作业最近一次执行是否成功；未满足则本次跳过并记录「已跳过」日志。保存时自动校验自依赖、依赖不存在与循环依赖。
- **批量操作**：作业列表支持多选后批量暂停 / 恢复 / 启用 / 禁用。
- **日志自动清理**：系统配置新增日志保留天数（默认 30 天）、最大条数与清理间隔，后台定时清理历史日志。
- **存储数据迁移**：文件 / MySQL / PostgreSQL / SQLite / SQL Server 五种存储任意互转，支持作业、日志、系统设置与通知；提供预检、进度轮询、合并 / 覆盖 / 替换三种写入模式与迁移后校验。

**优化**

- 日志管理新增「已跳过」状态展示与筛选。
- 数据迁移同步复制作业依赖字段。
- 数据迁移配置简化为单个 `Migration.AdditionalStore`，无需再维护命名配置档，旧版 `Profiles` 配置继续兼容。
- 数据迁移界面明确标识当前存储类型，文件存储路径改用相对路径展示；仅配置一种存储时隐藏源 / 目标表单并给出配置提示。

**兼容性**

- 与 .NET 8.0 / 10.0 完全兼容。
- 数据库存储模式需同步更新 EFCore 扩展包并执行迁移（新增 `Dependencies` 字段）。
